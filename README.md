# Aerial Crater Dataset

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24544435.svg)](https://doi.org/10.5281/zenodo.24544435)

## Опис проєкту

Цей репозиторій містить датасет аерофотознімків із розміченими кратерами та вирвами, утвореними внаслідок вибухів. Датасет створено для дослідження можливостей використання алгоритмів комп’ютерного зору та нейронних мереж, зокрема YOLO, для автоматизованого виявлення наслідків бойових дій на зображеннях, отриманих зверху.

Датасет використовується для підсилення дослідницької роботи МАН, присвяченої автоматизованому виявленню кратерів на зображеннях з метою подальшого аналізу уражених земель, оцінювання масштабів пошкоджень та планування відновлювальних робіт.

## Призначення датасету

Основною метою створення датасету є підготовка навчальних даних для моделей комп’ютерного зору, здатних автоматично виявляти кратери та вирви на аерофотознімках.

Датасет може бути використаний для:

- навчання моделей об’єктного розпізнавання;
- тестування алгоритмів комп’ютерного зору;
- автоматизованого аналізу пошкоджених територій;
- оцінювання кількості та розташування кратерів;
- підтримки досліджень, пов’язаних із повоєнним відновленням земель;
- побудови систем аналізу супутникових, дронових або інших зображень, отриманих зверху.

## Структура датасету

Репозиторій містить понад 700 зображень, на яких вручну розмічено кратери та вирви.

## Джерела зображень та умови використання

Зображення зібрано з відкритих джерел. Через воєнні дії систематичне знімання уражених територій, зокрема з БпЛА, значно ускладнене, тому частина зображень — це фрагменти супутникових знімків сервісів Google Maps / Google Earth (на таких зображеннях збережено позначку «© Google»). Права на ці зображення належать Google та відповідним постачальникам даних.

- Датасет призначено лише для некомерційного академічного використання.
- Використання зображень Google має відповідати [умовам використання Google Maps / Google Earth](https://www.google.com/help/terms_maps/) та [правилам використання геоконтенту Google](https://about.google/brand-resource-center/products-and-services/geo-guidelines/); зокрема, позначку «© Google» не можна видаляти.
- Розмітка (каталог `labels`) поширюється за ліцензією [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) (див. [LICENSE](LICENSE)); використання — з посиланням на цей набір даних.

Такий підхід поширений у відкритих наборах даних для дистанційного зондування (наприклад, DOTA, AID, NWPU-RESISC45 також побудовано на знімках Google Earth і поширено для академічного використання).
