# Aerial Crater Dataset

## Опис проєкту

Цей репозиторій містить датасет аерофотознімків із розміченими кратерами та вирвами, утвореними внаслідок вибухів. Датасет створено для дослідження можливостей використання алгоритмів комп’ютерного зору та нейронних мереж, зокрема YOLO, для автоматизованого виявлення наслідків бойових дій на зображеннях, отриманих зверху.

Датасет використовується для підсилення дослідницької роботи МАН, присвяченої автоматизованому виявленню кратерів на зображеннях з метою подальшого аналізу уражених земель, оцінювання масштабів пошкоджень та планування відновлювальних робіт.

## Призначення датасету

Основною метою створення датасету є підготовка навчальних даних для моделей комп’ютерного зору, здатних автоматично виявляти кратери та вирви на аерофотознімках.

Датасет може бути використаний для:

- навчання моделей об’єктного розпізнавання;
- тестування алгоритмів комп’ютерного зору;
- автоматизованого аналізу пошкоджених територій;
- оцінювання кількості та розташування кратерів;
- підтримки досліджень, пов’язаних із повоєнним відновленням земель;
- побудови систем аналізу супутникових, дронових або інших зображень, отриманих зверху.

## Структура датасету

Репозиторій містить понад 700 зображень, на яких вручну розмічено кратери та вирви.
